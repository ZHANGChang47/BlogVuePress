PRODUCT BRIEF · 2026-11

给你的光标，换一只猫。CatCursor 是 Windows 鼠标指针主题管理器：内置 5 套主题，也能 AI 生成或导入自己的主题，一键安装、随时还原。

Windows 7 / 8 / 10 / 115 套内置主题17 个光标槽位8 种光标姿态AI 生成 / 本地导入本机处理

01一句话定位

Windows 换指针，不必再逐项指定

装

  • 点一下写入 17 个光标槽位，并通知系统立即生效
  • 首次安装前自动备份原来的指针，随时可还原

换 / 造 / 传

  • 卡片上直接看出未安装、已装未用、使用中
  • AI 生成或导入 8 张图，自动封装成完整主题包
  • 任意主题都能导出成可右键安装的 zip

02启动方式

便携版、启动脚本、源码模式

方式怎么做适用
便携版双击 CatCursor-Portable-1.0.6.exe只用，不折腾环境
启动脚本双击「启动 CatCursor.bat」本机已有 Node 与 Electron
源码模式npm install 后 npm start要改界面或功能

便携版首次运行会自解压到带版本号的目录，之后复用这份结果。升级时直接用新 exe，旧目录可留可删。

03主界面

一屏看完当前状态、主题预览与入口

  • 顶部状态：绿点表示有主题正在生效，文字是主题名；灰点表示系统默认指针。
  • 当前主题预览：8 个姿态平铺展示，安装前先看效果。
  • 下方三个区块：默认主题、我的主题、生成新主题。

04主题卡片与三种状态

每张卡片把 8 个姿态排成 4×2，下面标出主题名、英文名和风格标签

卡片状态按钮含义
未安装安装文件还没复制到本机，点一下就装好并立即生效
已装未用使用文件已在，只需写入注册表即可切换，不重复复制
使用中使用中当前正在生效，卡片绿边高亮，顶部状态同步显示

内置主题不能删除；自建主题可以删除，只删本机文件，不影响系统当前指针。

05安装、切换、还原

一次安装做三件事，顺序不能颠倒

  1. 把主题包里的 17 个指针文件放到本机主题目录。
  2. 把这 17 个路径逐个写进当前用户的光标槽位。
  3. 调用系统接口通知桌面刷新，指针立刻变化，不用注销。
为什么要备份。第一次安装前会先读一遍当前 17 个槽位值并存成备份。「还原系统默认」时先写回这份备份；如果从未装过自定义指针，备份里就是 Windows 自带方案。所有写操作都在当前用户下，不需要管理员权限，也不影响其他账户。

06AI 生成新主题

分两段生成，先定住同一只猫，再补齐姿态

  1. 先生成基准图：只出 normal 姿态，确认猫长什么样。
  2. 再生成其余 7 个姿态：把基准图作为参考，保证 8 张是同一只猫。

接口配置

  • 选「火山方舟」风格时，Base URL 和模型会自动填好，只需粘 Key。
  • 「测试链接」只调模型列表，不生成图片，不产生费用。
  • Key 只写在本机配置里，不上传，不写进导出的主题包。
为什么分两步。一次出 8 张，第一张不满意就全废；分两步时只需重出一张，而且基准图是后面 7 张保持一致性的来源。

07导入本地图片

不想用 AI，就自己画 8 张

normal      text      link      forbidden
busy        move      horz      vert
  • 格式支持 PNG / JPEG，建议 1024×1024，浅色纯底或透明背景。
  • 导入时自动抠图、缩放、封装成 8 个 .cur 与 3 个 .ani。
  • 全过程纯前端完成，不需要额外安装 Python 或图像工具。

08导出可安装主题包

内置或自建主题都能导出，结构和常见网络主题包一致

  • 导出 zip 含右键安装 INF、使用说明、八姿态预览、实际大小预览和 Cursors 目录。
  • 收到的人解压后，右键 !右键安装.inf 即可安装到系统主题列表。
  • 一套主题约 320 KB，适合直接发给别人。
部分 Win11 会拦截 INF 安装。提示「此安装程序不受信任」时，按包里《使用说明.txt》的手动步骤操作即可。

09状态栏

所有耗时操作都有反馈，不用猜它卡没卡

状态样子什么时候
就绪灰点空闲，没有正在进行的操作
进行中转圈 + 计时安装、生成、导出等执行期间
完成绿点操作成功，保留 4 秒后回到就绪
失败红点 + 原因操作出错，同时显示具体原因

10常见问题

几个高频卡点

点安装后指针没变

看底部状态栏有没有报错。若提示写注册表失败，通常是安全软件拦截，把程序加入白名单后重试。

接口报 Key 格式错误

用了账号的 AccessKey / SecretKey。要的是方舟控制台「API Key 管理」里创建的 API Key。

装完想回到原来的指针

点「还原系统默认」，它会写回首次安装前备份的那 17 个值。

导出的 zip 右键没有安装

先解压，再对解压出来的 INF 右键；压缩包内直接右键不生效。

11已知限制

买前/用前需要知道的事

  • 只有方舟风格会把基准图作为参考图传给接口；其他兼容风格的一致性会明显下降。
  • 生成的 .cur 是 64×64 单尺寸，高 DPI 下由系统缩放，锐度不如原生多尺寸方案。
  • 导出包里的两张预览都是静态图，暂不含动画预览。
  • 只作用于当前用户，切换 Windows 账户后需要各自安装。
