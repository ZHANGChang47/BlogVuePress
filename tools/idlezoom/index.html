鼠标停住，一张高清图贴到光标上；一动立刻消失。贴图鼠标穿透，不挡点击、不影响打字——只是盖在上面。

Windows 10 / 11 x64exe 版免装环境托盘常驻可开机自启本机运行不联网不上传

01一句话定位

把当前光标变成一张可大可小的高清贴图

它做什么。静止超过设定时长，程序抓取此刻系统正在显示的光标，本地放大后贴到光标位置；鼠标一动立即消失。贴图窗口鼠标穿透，点击和键盘输入都落到下面的窗口，视觉上只多了一张照片。

02快速开始

三步跑起来

1 · 启动

双击 静止放大工具.exe，无控制台黑框。源码方式用 python app.py，需要 Python 3.9+ 与 Pillow。

2 · 开始监测

点「启动监测」，把鼠标停住不动。等过设定时长，贴图就会出现在光标位置。

3 · 收进托盘

右上角减号收进托盘，叉号退出。托盘左键打开面板，右键菜单开关监测。

单实例与配置

重复双击 exe 不会开出第二个实例，只会把已有面板叫到前面。参数写在 exe 同目录配置文件里，移动 exe 时一起带走。

03工作原理

四步，全部在本地完成

步骤做什么要点
检测静止轮询鼠标坐标，位移小于容差就累加计时默认 1.2 秒判定为静止
抓当前光标取系统此刻真正在显示的光标位图文本区是 IBeam，链接是 Hand，平时是 Arrow
本地放大预乘放大、去噪、强反锐化、对比度回补、alpha 阶跃纯 Pillow，无 AI 推理、无网络请求
分层贴图置顶透明窗口贴到光标位置，同时临时隐藏系统光标退出或一动即恢复
为什么不直接改系统光标。Windows 光标尺寸上限 256px，而主题源图通常只有 64px。把 64px 拉到 256px 再锐化，补不回不存在的细节。悬浮贴图直接画一张任意尺寸的透明窗口，不受这条限制。

04参数说明

界面里调完立即持久化

参数范围说明
静止时长0.2–10.0 秒，默认 1.2鼠标停多久触发贴图，滑杆步进 0.1 秒
贴图尺寸64–512 px，默认 192贴图长边像素，预设 128 / 192 / 256 / 320 / 384
位移容差0–10 px，默认 0小于这个位移算手抖；手不稳可调到 2–3
对准方式图片居中 / 箭头尖端猫抱箭头这类主题用箭头尖端更贴合视觉
自定义图片PNG / JPG用高分辨率原图替代自动抓取，清晰度上限更高
隐藏原光标开 / 关，默认开开时只看到照片；关时照片和小箭头叠加
开机自启开 / 关 + 延迟写当前用户启动项，不需要管理员权限
位移容差默认 0 是刻意的。0 意味着「只要动就隐藏」，响应最干脆。手放鼠标上有轻微抖动导致贴图闪烁时，再调到 2。

05素材从哪来

默认抓「此刻系统正在显示的光标」，不是永远一个箭头

鼠标所在位置抓到的光标贴出来的样子
桌面 / 普通窗口Arrow 标准箭头主题里的箭头图形
输入框 / 文本框IBeam 文本光标主题里的 I 形光标
网页链接 / 按钮Hand 手形主题里的手形光标
抓取失败时回退到主题箭头仍能正常显示，不会空白

这条设计的意义是通用：用户装什么主题就贴什么图，换一台陌生电脑照样工作，不需要预先准备素材。

06放大算法

针对插画风光标调的五步流水线

  1. 预乘 alpha 后 LANCZOS 放大：避免透明区域颜色渗进边缘形成灰边。
  2. 中值滤波去噪：清插值产生的孤立噪点，同时保住硬边缘。
  3. 强反锐化 + 限幅保护：把描边补回来，并压住深色描边外侧的白边。
  4. 大半径 clarity 回补中频：补回色块内部层次，这是「真切感」的主要来源。
  5. alpha 只做阶跃：边缘干净，不对 alpha 做锐化，避免灰晕。
关于 AI 超分。试过 waifu2x 路线，实测会把猫脸细节抹成色块，比传统锐化更差；引入模型还会让 exe 从 17MB 涨到上百 MB，所以没有集成。

07光标隐藏与恢复

「看不到原光标」是怎么做到的

系统光标由 Windows 画在所有窗口之上，任何窗口都盖不住它。要实现照片独占视线，只能在贴图出现时把光标本身临时换掉。

  • 贴图出现时用系统接口把 15 个光标角色替换成全透明光标；贴图隐藏时立刻恢复。
  • 透明图同时满足 32bpp alpha 合成和 AND mask 两条渲染路径，避免出现黑色小方块。
  • 注入后立刻读回校验，若渲染异常就回滚放弃隐藏。
  • 退出后按角色恢复真实光标，避免只重载系统设置导致的光标不显示。
  • 诊断日志记录每次注入与回滚，出错时能判断是尺寸、角色还是渲染路径问题。

08常见问题

几个高频疑问

贴出来的图还是糊

源主题只有 64px 时就这样，算法补不回原图没有的细节。换高分辨率指针主题，或在界面里选一张高清 PNG。

贴图会挡住点击吗

不会。窗口设了鼠标穿透，点击和键盘输入都落到下面，贴图只是视觉覆盖。

截图里为什么抓不到贴图

分层窗口用部分 GDI 截图方式抓不到，属正常现象。用系统截图或支持 DWM 合成的工具即可。

之前出现黑方块，现在还有吗

已修复：透明光标同时满足两条渲染路径、尺寸按系统实测值匹配，并有注入后校验，异常立即回滚。
