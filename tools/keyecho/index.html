KeyEcho 键鸣

让每一次敲击，都有机械键盘的回响。系统级全局按键监听 + Web Audio 实时程序合成的打字音效工具：不限当前窗口、零采样文件、不保存按键内容。

PRODUCT BRIEF · 2026-11

把任何键盘敲出机械键盘（或麻将、黄油、雨滴）的沉浸声感。

Windows 10 / 11全局监听 · 不限窗口14 种预设音色14 参数音色编辑器零采样 · 程序合成不保存按键内容

01一句话定位

产品是什么、给谁用

  • 是什么：打字音效增强工具。监听系统级键盘输入（不限当前窗口），为每次按键实时合成机械键盘质感的声音反馈。
  • 给谁用：笔记本薄膜键盘用户、机械键盘爱好者、想给打字增加仪式感与沉浸感的写作者 / 程序员 / 文字工作者。
  • 核心差异：声音是实时程序合成的（非音频采样），内置 14 种从轴体型号到中文键盘圈调音文化的预设，并提供 14 参数合成编辑器让用户创作并永久保存自己的专属音色。

02主界面总览

玻璃拟态界面 · 音色 / 参数 / 可视化一屏直达

03声音引擎

零采样文件 · 实时合成 · 复音叠加

程序合成引擎 CORE

  • Web Audio 实时合成，无任何音频素材文件——体积小、无版权风险、无素材授权问题
  • 48 kHz 输出，按下与回弹各有独立声音层（含可调回弹音）
  • 28 路复音上限 + 压缩器防爆音，快速连打不破音、超限自动淡出最旧音源
  • 预渲染 AudioBuffer，单键触发延迟极低

按键差异化 FEEL

  • 7 类按键独立音色行为：字母数字 / 空格 / 回车 / 退格 / Tab / 修饰键 / 功能键
  • 大键（空格、回车）有更低沉厚实的声底，还原真实键盘的层次感
  • 力度随机参数让每次敲击有轻微强弱变化，避免机械重复感
  • 按键分组可单独静音（如只留字母区、静音修饰键）

05自定义音色编辑器

创作并永久保存你自己的声音

创作流程

  • 从任一内置音色起步，或从空白开始
  • 14 项参数分「基础 / 进阶」两组：高频亮度、低频重心、低频厚度、撞击脆响、噪声量、饱满度、尾音长度、软起音（基础）；低频尾长、中频腔体、中频量、颗粒感、共振峰、整体音量（进阶）
  • 拖动滑块即实时重绘波形并试听，调音所见即所得
  • 保存后出现在「自定义音色」分组，与内置音色同等使用

管理与持久化

  • 支持多套自定义音色，命名保存（最多 16 字）
  • 卡片上直接编辑 / 删除（删除带两步确认防误触）
  • 设置与自定义音色本地持久化，重启不丢失
  • 存储内容仅为一条合成参数记录，不含任何按键数据

06声音参数与按键控制

三档微调 + 七组按键独立开关

基础参数

  • 主音量——整体响度
  • 回弹音——按键抬起时的释放音强度，真实键盘都有这一层
  • 力度随机——每次敲击的强弱随机幅度，越高手感越「活」

按键分组

  • 字母数字 / 空格 / 回车 / 退格 / Tab / 修饰键 / 功能键 七组独立开关
  • 点击即可开启或静音某一组（如写作时静音修饰键）
  • 每组有独立的音高、响度、亮度特征，还原真实大键差异

07会话统计与运行状态

打字数据可视化 · 系统状态一目了然

本次会话

  • 累计击键、键 / 分钟、并发音源数实时统计
  • 七个按键分组的使用频率条形图
  • 一键归零，随时开始新的统计

运行状态

  • 监听方式（系统级全局钩子 / 窗口内降级）、音频引擎、输出设备、当前版本
  • 「按键内容：不保存」常驻显示，隐私承诺可见
  • 开机自启开关（默认关闭，由用户自主决定）
  • 软件更新状态与检查入口

08系统集成与日常使用

装完即用 · 常驻不打扰

全局控制

  • 系统级全局键盘监听——游戏、终端、任何窗口内打字都生效
  • 全局快捷键 Ctrl + Alt + M 一键开关音效
  • 系统托盘常驻（图标区分开启 / 暂停两态），菜单内含快捷开关与更新检查
  • 单实例运行；关闭按钮为「隐藏到托盘」，不打断后台监听

安装与更新

  • 提供 NSIS 安装版与便携版两种分发形态
  • 开机自启由用户控制，默认关闭（便携版禁用该项并提示）
  • 自动更新：启动 / 每小时自动检查，更新内容可见后一键下载安装，静默升级至原安装目录并重启
  • 更新入口常驻吸顶状态栏，滚动页面时始终可见

09隐私与安全

打字内容零收集

隐私承诺：KeyEcho 只读取「按了哪个键」的事件类型以触发声音，不记录、不保存、不上传任何按键内容（打字正文绝不会被读取进存储）。除软件更新检查外不发起任何网络请求；无遥测、无账号体系、无素材下载。声音全部本地实时合成。

10系统需求

操作系统
Windows 10 / 11（64 位）
处理器 / 内存
任意 64 位双核 CPU，2 GB 内存
存储空间
约 300 MB（安装版含 Electron 运行时）
音频
任意系统默认输出设备
权限说明
键盘监听为用户级全局钩子，无需管理员权限；首次运行如被安全软件提示放行即可（监听型软件常见提示）
安装方式
NSIS 安装向导（支持自选目录、开机自启开关）或免安装便携版
